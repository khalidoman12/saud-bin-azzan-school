# الدليل المدرسي — مدرسة سعود بن عزان

تطبيق ويب عربي سريع للبحث في قوائم طلبة **مدرسة سعود بن عزان للتعليم الأساسي (5–8)** وتصفّح الصفوف والشعب وجداول المعلمين الأسبوعية.

## الوظائف الأساسية

- بحث لحظي بالاسم الكامل أو جزء منه.
- تطبيع عربي للبحث مع الحفاظ على الاسم الأصلي للطالب.
- فلترة متزامنة حسب الصف والشعبة.
- تصفّح الصف ← الشعبة ← قائمة الطلبة.
- عرض عدد الطلبة في كل شعبة.
- واجهة RTL متجاوبة مع الهاتف والكمبيوتر، ووضع فاتح وداكن.
- تشغيل كامل داخل المتصفح دون إرسال أسماء الطلبة إلى خدمة بحث خارجية.
- بحث لحظي عن المعلم مع فلاتر الصف والمادة واليوم والحصة؛ تُطابق جميع الشروط الحصة نفسها.
- عرض يومي للحصص الثماني، وعرض جدولي للأسبوع من الأحد إلى الخميس، مع تمييز الحصص المزدوجة.
- إظهار تاريخ نسخة الملف وصفحة المصدر، وأزرار مباشرة للأيام والحصص.
- قوائم مستقلة لمعلمي الصفوف الخامس والسادس والسابع والثامن.

## البيانات

تحتوي النسخة الحالية على **1,395 طالبًا** موزعين على **39 شعبة**، و**85 معلمًا** مع **1,520 موعدًا** يعادل **1,558 حصة فعلية** (منها 38 موعدًا مزدوجًا). المصدر الحالي **الجدول العام للمعلمين.pdf** بتاريخ **2026-09-19**. جرى استخراج الأسماء والجداول من ملفات المدرسة دون تغيير أسماء الأشخاص، ويُستخدم التطبيع العربي لأغراض المطابقة فقط.

بيانات المعلمين المولدة موجودة في `data/teachers.generated.json`، وتقرير التحقق في `data/teachers-import-report.json`. ويمكن إعادة الاستيراد بالأداة `tools/import_teacher_schedules.py` عند توافر ملف PDF المصدر محليًا.

تُطابق أداة مستقلة `tools/audit_teacher_schedules.py` جميع الخلايا باستخدام PyMuPDF مقابل استخراج pdfplumber، وتنتج `data/teachers-independent-audit.json`. تتضمن المراجعة بصمة المصدر والأسماء والمواد والشعب والأيام والحصص والأوقات، دون استيراد كود المستخرج الأساسي. لا تُرفع ملفات PDF إلى المستودع.

```bash
python3 tools/import_teacher_schedules.py INPUT.pdf --output data/teachers.generated.json --report data/teachers-import-report.json
python3 tools/audit_teacher_schedules.py INPUT.pdf data/teachers.generated.json --report data/teachers-independent-audit.json
```

ملاحظات المصدر التي لم تُعدّل بالتخمين: صفحات 80–85 فارغة، والاسمان «س س» و«ص ص» كما وردا، ولم تُدرج حصتان للشعبة 8/2 (الثلاثاء والأربعاء، الحصة الثامنة). أوقات الحصص من ترويسة PDF ولا يُستنتج منها آليًا «المعلم المتاح الآن». الخانة الفارغة لا تثبت تفرغ المعلم للاحتياط.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث:

```bash
npm ci
npm run dev
```

## الاختبار والبناء

```bash
npm test
npm run build:static
```

يُنشر الموقع تلقائيًا عبر GitHub Pages عند تحديث فرع `main`.

## تنبيه الخصوصية

هذا المستودع وموقع GitHub Pages عامّان، ولذلك تكون بيانات الطلبة والمعلمين المضمّنة فيهما متاحة لمن يصل إليهما. عند إضافة الحضور أو المتابعات أو الملاحظات مستقبلًا يجب نقل النظام إلى استضافة خاصة مع تسجيل دخول وصلاحيات؛ ولا ينبغي إضافة أي بيانات نفسية أو سلوكية حساسة إلى هذه النسخة العامة.
