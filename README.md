# الدليل المدرسي — مدرسة سعود بن عزان

تطبيق ويب عربي سريع للبحث في قوائم طلبة **مدرسة سعود بن عزان للتعليم الأساسي (5–8)** وتصفّح الصفوف والشعب وجداول المعلمين الأسبوعية وأرشيف الأنشطة والبرامج المدرسية.

## الوظائف الأساسية

- بحث لحظي بالاسم الكامل أو جزء منه.
- تطبيع عربي للبحث مع الحفاظ على الاسم الأصلي للطالب.
- فلترة متزامنة حسب الصف والشعبة.
- تصفّح الصف ← الشعبة ← قائمة الطلبة.
- عرض عدد الطلبة في كل شعبة.
- واجهة RTL متجاوبة مع الهاتف والكمبيوتر، ووضع فاتح وداكن.
- تشغيل كامل داخل المتصفح دون إرسال أسماء الطلبة إلى خدمة بحث خارجية.
- بحث لحظي عن المعلم مع فلاتر الصف والمادة واليوم والحصة؛ تُطابق جميع الشروط الحصة نفسها.
- عرض يومي للحصص الثماني، وعرض جدولي للأسبوع من الأحد إلى الخميس، مع تمييز الحصص المزدوجة.
- إظهار تاريخ نسخة الملف وصفحة المصدر، وأزرار مباشرة للأيام والحصص.
- قوائم مستقلة لمعلمي الصفوف الخامس والسادس والسابع والثامن.
- أرشيف قابل للبحث للفعاليات والأعمال المدرسية مع الصور والتصنيفات والفئات المستفيدة.
- قسم مستقل لأنشطة وأعمال الأخصائيين النفسيين والاجتماعيين.
- مزامنة مجانية مجدولة للمنشورات العامة الجديدة من حساب المدرسة `@EduGovSsq5302` بلا مفتاح API أو خدمة ذكاء اصطناعي مدفوعة.

- جداول أسبوعية مستقلة لجميع الشعب، مع المادة واسم المعلم ورابط لجدوله.
- أداة «أين المعلم؟» لعرض الشعب ومعلميها حسب اليوم والحصة المختارين.
- حفظ الشعب المفضلة محليًا، ونسخ رابط الشعبة وطباعة جدولها.

## البيانات

تحتوي النسخة الحالية على **1,395 طالبًا** موزعين على **39 شعبة**، و**85 معلمًا** مع **1,521 موعدًا** يعادل **1,560 حصة فعلية** (منها 39 موعدًا مزدوجًا). المصدر الحالي **جدول المعلمين .pdf** و**جدول الحصص للشعب.pdf** بتاريخ **2026-09-19**. جرى استخراج الأسماء والجداول من ملفات المدرسة دون تغيير أسماء الأشخاص، ويُستخدم التطبيع العربي لأغراض المطابقة فقط.

بيانات المعلمين المولدة موجودة في `data/teachers.generated.json`، وتقرير التحقق في `data/teachers-import-report.json`. ويمكن إعادة الاستيراد بالأداة `tools/import_teacher_schedules.py` عند توافر ملف PDF المصدر محليًا.

بيانات الأنشطة موجودة في `data/activities.generated.json`. يتضمن الأرشيف الأخبار المتاحة من 2026-08-30 إلى 2026-09-21، ولا يُدّعى اكتماله، وتفحص مهمة GitHub Actions العامة الحساب كل ساعة. اختير الفحص المتكرر لأن صفحة X العامة تعرض عددًا محدودًا من أحدث المنشورات للزائر غير المسجل.

المزامنة المجانية «أفضل جهد»: قد يغيّر X صفحته أو يمنع الوصول العام مؤقتًا. عند حدوث ذلك تفشل المهمة بوضوح دون حذف أو تعديل الأرشيف السابق. تحفظ أداة `tools/cache_activity_media.py` الصور الأصلية داخل الموقع لتقليل الاعتماد على تحميلها مباشرة من X، وتبقى روابط المصدر محفوظة. يمكن تشغيلها يدويًا من تبويب Actions، أو اختبارها محليًا:

```bash
python3 tools/sync_x_activities.py
```

تُطابق أداة مستقلة `tools/audit_teacher_schedules.py` جميع الخلايا باستخدام PyMuPDF مقابل استخراج pdfplumber، وتنتج `data/teachers-independent-audit.json`. تتضمن المراجعة بصمة المصدر والأسماء والمواد والشعب والأيام والحصص والأوقات، دون استيراد كود المستخرج الأساسي. لا تُرفع ملفات PDF إلى المستودع.

```bash
python3 tools/import_teacher_schedules.py INPUT.pdf --output data/teachers.generated.json --report data/teachers-import-report.json
python3 tools/audit_teacher_schedules.py INPUT.pdf data/teachers.generated.json --report data/teachers-independent-audit.json
```

ملاحظات المصدر التي لم تُعدّل بالتخمين: صفحات 80–85 فارغة، والاسمان «س س» و«ص ص» كما وردا؛ وقد اكتملت حصص 8/2 في الملف الجديد. أوقات الحصص من ترويسة PDF ولا يُستنتج منها آليًا «المعلم المتاح الآن». الخانة الفارغة لا تثبت تفرغ المعلم للاحتياط.

## تنبيه الخصوصية

هذا المستودع وموقع GitHub Pages عامّان، ولذلك تكون بيانات الطلبة والمعلمين المضمّنة فيهما متاحة لمن يصل إليهما. عند إضافة الحضور أو المتابعات أو الملاحظات مستقبلًا يجب نقل النظام إلى استضافة خاصة مع تسجيل دخول وصلاحيات؛ ولا ينبغي إضافة أي بيانات نفسية أو سلوكية حساسة إلى هذه النسخة العامة.

## مطابقة جدول الشعب

تستخرج أداة `tools/import_class_schedules.py` جدول الشعب من PDF باستخدام مواضع الحروف وحدود الجدول ثم تقارنه بجدول المعلمين المستخرج مستقلاً. النتيجة في `data/classes-cross-audit.json`: 39 شعبة × 5 أيام × 8 حصص = 1,560 مطابقة، دون اختلاف. تحافظ البيانات على أسماء PDF المختصرة وتربطها بالاسم الكامل؛ لا تُستنتج أوقات الدوام أو تفرغ المعلم.

## مراجعة أخبار 21 سبتمبر

روابط المنشورات والصور الأصلية هي المرجع. يميّز الحقل `verifiedAt` الأخبار التي أعيدت قراءتها من منشورها الأصلي؛ السجلات السابقة غير المعاد التحقق منها تحمل في الواجهة عبارة «تاريخ أرشيفي قيد التحقق». لا يساوي نجاح الفحص اكتمال الأرشيف؛ الصفحة العامة تعرض عينة حديثة فقط. لإكمال الأخبار التي لم تظهر، يلزم تصدير الحساب أو تزويد روابط المنشورات الناقصة. لا تستخدم المزامنة خدمة AI مدفوعة أو مفاتيح وصول.
