# رصد الموهبة — نظام كشف الطلبة الموهوبين

تطبيق عربي مستقل داخل مستودع مدرسة سعود بن عزان البوسعيدي (5–8)، مُنشأ في مجلد `talent-system/` دون تغيير الدليل المدرسي المنشور.

## الأقسام

تسع مواد: التربية الإسلامية، اللغة العربية، الرياضيات، الإنجليزية، الدراسات الاجتماعية، العلوم، المهارات الموسيقية، الرياضة المدرسية، الفنون التشكيلية. إضافة إلى **مسؤول مصادر التعلم**، و**بوابة الأخصائي النفسي والاجتماعي**، و**سجل شامل مستقل ومقفل**.

لكل قسم نموذج خاص، وقائمة مواهب، وعشرة مؤشرات وصفية. الخيارات: تنطبق بوضوح / جزئيًا / لا تنطبق / لم تتح فرصة للملاحظة. حقل رأي لجنة الموهوبين **اختياري**، ويضيفه الأخصائي المخوّل لاحقًا دون تعديل تقييم المعلم. السجل يعرض الترشيحات ويمكن البحث والتصفية والطباعة وتصدير CSV لفتحه في Excel.

الاستمارات **نماذج ترشيح أولي** وليست اختبارات نفسية مقننة. لا يُستنتج وصف نهائي للموهبة من مجموع الإجابات وحده.

## التشغيل محليًا

يلزم Python 3.11+ وخادم خاص؛ **GitHub Pages وحده لا يدعم قاعدة البيانات أو حماية البيانات الحساسة**.

```bash
cd talent-system
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python setup_pins.py
TALENT_COOKIE_SECURE=false uvicorn server:app --host 127.0.0.1 --port 8088
```

افتح http://127.0.0.1:8088/ . في ويندوز شغّل `.venv\\Scripts\\activate` وتهيئة المتغيرات بصيغة PowerShell.

**لا تستخدم** `TALENT_COOKIE_SECURE=false` في الإنترنت؛ هو فقط للتجربة المحلية غير المشفرة. في الاستضافة الفعلية استخدم HTTPS وشهادة TLS مع `TALENT_COOKIE_SECURE=true` (القيمة الافتراضية). قاعدة البيانات موجودة في `talent-system/private/talent.sqlite3` وهي مستبعدة من Git. يمكنك تعيين مكان تخزين خاص عبر `TALENT_DB_PATH`.

`python setup_pins.py` يطلب رمزًا رباعيًا فريدًا لكل قسم ويخزن مشتقًا مشفرًا مملحًا منه في قاعدة بيانات **الخادم فقط**. لا تضع الرموز في GitHub أو داخل ملفات JavaScript أو GitHub Actions العامة.

### مهم للأمن والتشغيل

- المشروع نموذج تشغيل أولي، وليس نظامًا معتمدًا لحفظ بيانات القاصرين في الإنتاج.
- 4 أرقام = 10,000 احتمال فقط. حتى مع قفل المحاولات وتجزئة الرموز، لا تُعد حماية كافية بمفردها؛ أضف هوية فردية موثقة للمعلم وتحققًا مؤسسيًا متعدد العوامل قبل إدخال أي بيانات حقيقية.
- الآلية الحالية تقلل محاولات التخمين على **عملية خادم واحدة** فقط، ويجب إضافة حدود محاولات مركزية عند تعدد الخوادم، وتسجيل دخول فردي، وتدقيق سجلات النفاذ، وسياسات احتفاظ وموافقات ملائمة.
- أسماء الطلبة وملاحظات المعلمين لا تُحفظ في GitHub، ولا ينبغي نشر قاعدة البيانات أو النسخ الاحتياطية.
- النسخة الأولى تحفظ **وصف الأدلة نصيًا** فقط؛ لا تدعم رفع ملفات الطالب حتى ينفّذ تخزين مرفقات خاص وآمن.
- لا يوجد حفظ مسودة بعد؛ الحفظ النهائي متاح، ويجب استكمال مؤشرات كل مادة أو اختيار «لم تتح فرصة للملاحظة».
- يتم تقدير العدد الفريد بناءً على الاسم والصف؛ يلزم إضافة رقم طالب داخلي عند الاعتماد النهائي.
- رمز القسم مشترك، لذلك لا يُعد إثباتًا موثوقًا للهوية الفردية لمكتشف الموهبة؛ ينبغي إضافة حسابات المعلمين قبل الاستخدام الرسمي.
- يتطلب توفير خادم خاص وقاعدة بيانات وسياسة نسخ احتياطي، ثم اختبار الصلاحيات والخصوصية.

## إجراءات التحقق

```bash
python -m py_compile criteria.py server.py setup_pins.py
node --check public/app.js
```
